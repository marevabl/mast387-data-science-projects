# Data Science Projects – MAST 387

This repository showcases a collection of applied data science projects completed as part of the **Data Science Lab (MAST 387)** at Concordia University.

⚠️ **Note on data availability**  
Due to course restrictions, the original datasets used in the class cannot be shared publicly.  
To maintain reproducibility and transparency, this repository:
- uses **synthetic or public datasets** where appropriate
- focuses on **methodology, implementation, and analysis**
- preserves the original **data science pipeline**

---

## 🔹 Project 1: Sparse Recovery

**Techniques:**  
- Matching Pursuit (MP)  
- Orthogonal Matching Pursuit (OMP)  
- Convergence analysis  

**Highlights:**  
- Implemented MP and OMP from scratch  
- Generated synthetic sparse signals  
- Compared convergence speed and reconstruction error  

📁 Folder: `sparse_recovery/`

---

## 🔹 Project 2: Image Compression

**Techniques:**  
- Singular Value Decomposition (SVD)  
- Haar Wavelet Decomposition  
- Memory-efficiency comparison  

**Highlights:**  
- Analyzed singular value decay  
- Compared SVD vs wavelet compression  
- Visualized reconstruction quality  

📁 Folder: `image_compression/`

---

## 🔹 Project 3: House Price Regression

**Techniques:**

**Highlights:**  
- Log transformations and correlation analysis

## 🔹 Project 4: Air Quality Modeling
